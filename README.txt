Power BI Dashboard
Описание задачи
Данный проект построен на основе выгрузки из маркетплейса Olist (Бразилия).
Основная задача — создать в Power BI аналитический дашборд, который поможет:

- понять динамику продаж по объему заказов и по выручке
- выяснить регионы/города-лидеры по выручке
- рассчитать средний чек по заказу и среднее количество заказов на продавца
- определить долу транспортных расходов в валовой выручке, определить товарные категории с самым выгодным соотношением транспортных расходов к валовой выручке
- рассчитать процент выкупа заказов
- определить количество покупателей по количеству совершенных покупок
- рассмотреть товарные группы по соотношению массы посылок к их объему, есть ли зависимость количества купленных товаров к их "плотности", вычислить общие объемы грузоперевозок маркетплейса

В дашборде четыре блока, между которыми можно переключаться с помощью кнопок внизу: Продажи по датам, Информация для продавца, Эффективность продаж маркетплейса,  Выгодные категории по стоимости и объему. 

Ключевые метрики и визуализации Продажи по датам
1. На странице выведены карточки с основными метриками :
- Количество продавцов
- Количество заказов
- Валовая выручка
- Средняя выручка за заказ
- Среднее количество заказов на продавца
2. Выручка по датам
Позволяет отслеживать сезонность и видеть тренды (рост или падение).
3. Количество заказов во времени
4. Выручка по штатам (ТОП 10)
5. Выручка по городам (ТОП 10)

Ключевые метрики и визуализации Информация для продавца
1. На странице выведены карточки с основными метриками :
- Транспортные расходы по выбранным категориям
- Выручка по оплаченным заказам
2. ТОП 15 проданных товаров по категориям в стоимостном выражении
3. Категории товаров по соотношению транспортных расходов к выручке

Ключевые метрики и визуализации Эффективность продаж маркетплейса
1. На странице выведены карточки с основными метриками :
- Число заказов
- Количество выкупленных заказов
- Количество невыкупленных заказов
- % выкупа заказов
- Количество заказов, произведенных клиентами более 1 раза
- Количество уникальных покупателей
- Количество продавцов
2. Количество покупателей по объему совершенных покупок. 
3. Процент выкупа заказов по объему соверщенных покупок.

Ключевые метрики и визуализации Выгодные категории по стоимости и объему
1. На странице выведены карточки с основными метриками :
- Валовая выручка по выбранным товарам
- Валовая выручка
- Общий объем грузоперевозом, м3
- Общий вес грузоперевозок, кг
2. ТОП 15 доставленных товаров по категориям в шт 
3. ТОП 15 проданных товаров по категориям в стоимостном выражении
4. Объем заказов по категориям в соответствии с плотностью заказа (масса/объем)
